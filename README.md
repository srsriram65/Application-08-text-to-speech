# 🔊 Application 08 - Smart Text-to-Speech

## 🎯 Aim

To convert written text into spoken audio using JavaScript Speech Synthesis API.

## 📖 Description

Text-to-Speech (TTS) is a speech processing technology that converts written text into human-readable speech.

This application provides an interactive interface where users can enter text and listen to it using different voice and speech settings.

## ✨ Features

- 🔊 Text-to-Speech conversion
- 🎙️ Multiple voice selection
- ⚡ Adjustable speech speed
- 🎵 Adjustable pitch
- 🔉 Adjustable volume
- ⏸️ Pause speech
- ▶️ Resume speech
- ⏹️ Stop speech
- 📋 Copy text
- 🗑️ Clear text
- 🔢 Word and character counter
- 📱 Responsive mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Speech API

## ⚙️ How It Works

1. User enters text into the text area.
2. Available browser voices are loaded.
3. User selects a voice.
4. Speech speed, pitch and volume can be adjusted.
5. The Speech Synthesis API converts the text into speech.
6. The user can pause, resume or stop the speech.

## 🧪 Example

### Input

Welcome to Text and Speech Analysis.

### Output

The browser reads the entered text aloud.
